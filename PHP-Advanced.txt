Object Oriented Programming:
Object Oriented Programming(oops) is a programming paradigm based on the concept of "objects",
which contain data(attributes) and code(methods).

Class: collection of attributes and methods: user defined data structure
keyword:class

Object: Instance of class: member of class:attributes:properties.

Constructor: Used to inisialize the objects and methods of class.

Magic Methods:
__construct():This magic method is the constructor of a class and is automatically called when an object is created. 
              It is used to initialize object properties and perform any necessary setup.

__call():This magic method is triggered when invoking inaccessible or non-existent methods of an object. 
         It allows you to define custom logic for handling method calls.

__toString():The __toString() magic method is called when an object is treated as a string, such as when using the echo or print functions. 
             It allows you to define a string representation of the object.

__callStatic():Handle undefined or inaccessible method calls, offering dynamic method dispatching and pre/post method execution actions.

__desrtuct():The __destruct() magic method is called automatically when an object is no longer referenced or when the script finishes execution. 
             It is used to perform cleanup tasks or release resources held by the object.

__get():This magic method is invoked when accessing inaccessible or non-existent properties of an object. 
        It allows you to define custom logic for retrieving the value of a property.

__set():The __set() magic method is triggered when assigning a value to an inaccessible or non-existent property of an object. 
        It allows you to define custom logic for setting the value of a property.

__invoke():Triggered when an object is called as if it were a function(e.g, $obj()).

__clone(): Executed immediately after an object has been cloned using the clone keyword.

Polymorphism:
Polymorphism is the ability of an entity-such as a variable, function, or object- to take on multiple forms,
commonly defined as "one interface, multiple methods".

Overloading: compile-time polymorphism
Overriding: run-time polymorphism

Compile-time(Static) Polymorphism: Achieved via methods overloading 
(using the same method name with different parameters).

Run-time (Dynamic) Polymorphism: Achieved via methods overriding
(subclass redefines a superclass method).

__construct():
The most common magic method. It runs automatically when you create a new instance of a class.
example:
class Database {
    public function __construct(string $dsn){
      echo "Connecting to: $dsn";
}
}
$db = new Database('mysql:host=localhost');

__destruct():
The cleanup crew. It runs when there are no more references to an object or during the script shutdown.
Example:
class FileLogger{
  public function __destruct(){
   echo "Closing file handles and cleaning up memory.";
}
}
$logger = new FileLogger();
unset($logger);

__call():
Triggered when invoking an inaccessible or non-existent method in an object context. Great for API wrappers.
Example:
class RestClient {
   public function __call($name, $arguments){
   return "you tried to call '$name' with " .implode(', ',$argument);
}
}
$api = new RestClient();
echo $api->getUsers('admin',20);

__callStatic():
The static version of __call(). Triggered when calling a non_existent static method.
Example:
class Finder{
  public static function __callStatic($name,$arguments){
 return "Searching for $name with criteria: ". $argument[0];
}
}
echo Finder::whereEmail('test@example.com');

__get():
Invoked when reading data from inaccessible (protected/private) or non-existing properties.
Example:
class User{
  private array $data = ['role' => 'Editor'];
  public function __get($name){
    return $this->data[$name] ?? 'property not found';
}
}
$u = new User();
echo $u->role;

__set():
Invoked when writing data to inaccessible or non-existing properties.
Example:
class DynamicCofig{
   private array $settings = [];
   public function __set($name,$value){
   $this->settings[$name] = $value;
}
}
$conf = new DynamicCofig();
$conf->timeout = 30;

__isset():
Triggered by calling isset() or empty() on inaccessible properties.
Example:
class Container{
  private $storage = ['id' => 1];
   public function __isset($name){
   return isset($this->storage[$name]);
}
}
$c = new Container();
var_dump(isset($c->id));

__unset():
Invoked when unset() is used on inaccessible properties.
Example:

class Session{
  private $vars = ['user' => 'Jhon'];
   public function __unset($name){
    unset($this->vars[$name]);
    echo "Unset $name";
}
}
$s = new Session();
unset($s->user);

__serialize() and __unserialize():
The modern way to handle object serialization. They return/receive an array representing the object's state.
class Connection{
     private $dsn;
     private $active = true;
    public function __serialize(): array{
     return ['dsn' => $this->dsn];
}
public function __serialize(array $data): void {
    $this->dsn = $data['dsn'];
    $this->active = true;
}
}

__sleep() and __wakeup():
The "legacy" version of serialization. __sleep returns an array of property names to save; __wakeup re-establishes connection.
Example:
class Olddb{
  public function __sleep(){
  return ['host', 'user'];
}
public function __wakeup(){
   $this->connect();
}
}

__toString():
Allows a class to decide how it will react when it is treated like a string(e.g, echo $obj).
Example :
class Product{
  public function __toString(){
    return "Product ID: 101 (Active)";
  }
}

$p = new Product();
echo $p;

__invoke() :
Allows you to call an object as if it were a function. Very useful for "Action" or "Command" classes.

Example :
class Sum{
  public function __invoke(...$nums){
    return array_sum($nums);
  }
}

$adder = new sum();
echo $adder(5, 10, 15);

A static method called for classes exported by var_export().

class Theme{

    $obj = new Theme();

__clone() :
Triggered when the clone keyword is used, Essential for "deep copying" objects that conatin other object

Example :
class Report{
   public $date;
   public function __clone(){
     //Ensure the clone report gets its own Date object, not a reference 
     $this->date = clone $this->date;
   }
}
