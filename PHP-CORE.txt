What is PHP?

PHP is a server-side scripting language, 
which is used to manage dynamic web pages, 
databases and build websites with features like session tracking and e-commerce.
PHP is a general-purpose scripting language,
It was created by Danish-Canadian programmer Rasmus Lerdorf in 1993 and released in 1995.
PHP was originally an abbreviation of Personal Home Page,
but it now stands for the recursive backronym PHP: Hypertext Preprocessor.
PHP development began in 1993.
when Rasmus Lerdorf wrote several Common Gateway Interface (CGI) programs in C,
which he used to maintain his personal homepage. 
He extended them to work with HTML forms and to communicate with databases, 
and called this implementation "Personal Home Page/Forms Interpreter" or PHP/FI.
NOW leatest version of PHP is: (8.5.4)12 March 2026;

=>Real Life Flow:-
1.User form fill kare → $_POST
2.URL me data bheje → $_GET
3.Login kare → $_SESSION
4.Browser me data save → $_COOKIE
5.File upload kare → $_FILES
6.Server info → $_SERVER

$_GET / $_POST: Used to collect data from HTML forms and URL PARAMETERS.

$_SESSION: Stores data across multiple pages for a specific user.

$_SERVER: Contains information about headers, path and script locations.

$_FILES: Handles file uploads to the script.

$_COOKIE: Accesses data sent by the browser via http cookies.
